# Telegram Voice Converter — версия для Render

Бот принимает аудиофайл, конвертирует его через FFmpeg в OGG/Opus и отправляет методом Telegram `sendVoice`. Результат отображается именно как голосовое сообщение, а не как музыкальный файл.

## Что добавлено

- HTTP-сервер `/health` и `/` для Render и внешнего мониторинга.
- Dockerfile с автоматической установкой FFmpeg.
- Ограничение размера входящего файла (по умолчанию 20 МБ).
- Ограничение числа параллельных конвертаций.
- Тайм-аут FFmpeg, временные каталоги и обработка ошибок.
- Команды `/start` и `/help`.

## Развёртывание на Render Free

### 1. Подготовь GitHub-репозиторий

1. Распакуй архив проекта.
2. Создай новый репозиторий на GitHub.
3. Загрузи в него все файлы проекта. Файл `.env` и токен в GitHub загружать нельзя.

### 2. Создай Web Service на Render

1. Открой https://render.com/ и войди через GitHub.
2. Нажми **New → Web Service**.
3. Подключи репозиторий с ботом.
4. Render должен определить Dockerfile. Если попросит параметры, выбери:
   - Runtime: **Docker**
   - Instance Type: **Free**
   - Dockerfile Path: `./Dockerfile`
   - Docker Build Context Directory: `.`
5. В разделе **Environment** добавь переменную:
   - Key: `BOT_TOKEN`
   - Value: токен, который выдал `@BotFather`
6. В настройках сервиса укажи Health Check Path: `/health`.
7. Нажми **Create Web Service** и дождись успешного Deploy.

Можно также использовать `render.yaml` через Blueprint, но для первого запуска проще создать Web Service вручную.

### 3. Проверь запуск

После деплоя Render покажет адрес вида `https://telegram-voice-converter.onrender.com`.

Открой в браузере:

- `https://ТВОЙ-СЕРВИС.onrender.com/health`

Должен вернуться JSON со статусом `ok`. После этого открой бота в Telegram и отправь `/start`.

## Как не дать бесплатному Render уснуть через 15 минут

У Render Free Web Service засыпает после 15 минут без входящего HTTP-трафика. Сам Telegram long polling не считается входящим HTTP-трафиком на твой Render-сервис: соединение инициирует сам бот наружу.

Для хобби-проекта можно использовать внешний мониторинг:

1. Зарегистрируйся на https://uptimerobot.com/ — у них есть бесплатный тариф.
2. Нажми **Add New Monitor**.
3. Выбери тип **HTTP(s)**.
4. В поле URL вставь `https://ТВОЙ-СЕРВИС.onrender.com/health`.
5. Установи интервал проверки **5 minutes** (на бесплатном тарифе UptimeRobot это стандартный интервал).
6. Сохрани монитор.

Каждый запрос к `/health` создаёт входящий трафик и обычно не даёт сервису простаивать 15 минут. Проверки должны идти регулярно; если монитор остановлен, URL неверный или сам Render перезапустит сервис, бот может временно стать недоступен.

**Важно:** это не превращает Free в гарантированный always-on хостинг. Render может перезапускать бесплатные сервисы, а после 15 минут без входящих запросов они засыпают. У Render также есть лимит 750 бесплатных instance-hours на рабочее пространство в месяц. Не используй такой вариант для критически важного бота. Если нужна гарантированная работа 24/7, нужен платный always-on хостинг или другой хост, который явно разрешает постоянные фоновые процессы.

## Настройки и лимиты

В Render → Environment можно менять:

| Переменная | По умолчанию | Назначение |
|---|---:|---|
| `BOT_TOKEN` | — | Токен Telegram от BotFather |
| `PORT` | `10000` | Порт HTTP-сервера (Render задаёт его автоматически) |
| `MAX_DOWNLOAD_MB` | `20` | Максимальный размер входящего файла |
| `MAX_CONCURRENT_CONVERSIONS` | `2` | Одновременно обрабатываемые файлы |
| `FFMPEG_TIMEOUT_SECONDS` | `240` | Максимальное время одной конвертации |
| `LOG_LEVEL` | `INFO` | Уровень логирования |

Обычный облачный Telegram Bot API ограничивает скачивание файлов ботом размером до 20 МБ. Лимит отправки голосового сообщения — до 50 МБ. Эти ограничения Telegram не увеличиваются настройками Render.

## Если бот не отвечает

1. Проверь Render → Logs: нет ли `BOT_TOKEN` missing или ошибки Telegram API.
2. Проверь `/health` в браузере.
3. Убедись, что монитор UptimeRobot активен и проверяет именно HTTPS URL `/health`.
4. Если менял токен, сохрани Environment и сделай Manual Deploy.
5. Не запускай два экземпляра одного бота с одним токеном одновременно: два long-polling процесса будут конфликтовать за обновления Telegram.

## Локальный запуск

Нужны Python 3.10+ и FFmpeg. Скопируй `.env.example` в `.env`, заполни `BOT_TOKEN`, затем:

```bash
pip install -r requirements.txt
python bot.py
```

На локальном компьютере HTTP-сервер использует порт `10000` по умолчанию.
